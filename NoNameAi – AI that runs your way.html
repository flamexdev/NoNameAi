FAQ


Frequently asked questions.


Quick answers about NoNameAi.




Is NoNameAi free to use?
The project is released under the Unlicense, which places it in the public domain, so you can use and modify it freely.


Do I need my own API key?
No. You can use the built-in API for a simple start, or connect your own API key if you prefer.


Can I run AI models locally?
Yes. The app lets you run an AI model you’ve downloaded on your own device.


What is Code Mode?
Code Mode is built for generating advanced code, working through large coding projects and handling complex programming tasks.


Where can I download it?
Builds are published on the GitHub Releases page. The project is young, with a new update planned every month.


How can I report a problem or follow progress?
Open an issue or star the repository on GitHub to stay up to date.
